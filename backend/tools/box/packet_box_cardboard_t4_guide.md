# Cutting guide: cardboard box, 4 mm board

Written by `box_pattern.py` from the same numbers as the drawing. All sizes are mm.

## Check the board first

- Thickness: this guide is for 4 mm board. If yours differs by more than 0.5 mm, run the script again with your thickness.
- Flutes (the ribs inside the board) run along the 624.4 length of the body.
- Keep old creases, holes and print seams out of every piece.
- Mark out on the plain inside face. That face ends up inside the box.
- The drawing ending `_on_wardrobe_box.svg` shows where the body and lid sit on a 20 x 20 x 34 in wardrobe box.

## Pieces

| Piece | Size | Number |
|---|---|---|
| Body blank | 624.4 x 489.8 | 1 |
| Lid | 224.6 x 282.0 | 1 |

## Body: mark out

Draw a rectangle 624.4 x 489.8. Take every measurement from an edge of this rectangle.
The blank is the same from both ends and from both long edges, so mark each distance twice.

Along the length, from each end:

| mm | Line |
|---|---|
| 0.0 | tab tips, the end of the blank |
| 12.0 | return panel edge |
| 22.8 | crease D, drop to return |
| 28.8 | window edge nearer the end |
| 33.1 | hem free edge, the other window edge |
| 44.8 | crease C, ledge to drop, and the hem fold |
| 57.6 | crease B, end wall to ledge |
| 77.4 | wall slot edge nearer the end |
| 81.9 | wall slot, other edge |
| 183.0 | dust flap end |
| 204.0 | crease A, floor to end wall |
| 208.0 | dust flap crease, the end of the side wall |
| 312.2 | centre of the blank |

Across, from each long edge:

| mm | Line |
|---|---|
| 0.0 | side wall edge, the long edge of the blank |
| 1.0 | dust flap outer edge |
| 144.4 | dust flap inner edge |
| 148.4 | long strip edge, and the floor to side wall crease |
| 164.9 | window and hem ends |
| 184.4 | wall slot end |
| 184.9 | tab edge |
| 214.9 | tab edge |
| 215.4 | wall slot end |
| 244.9 | centre of the blank |

## Body: cut

1. Corners. Cut away the four corner rectangles, each 183.0 along the length and 148.4 across. This leaves a long strip 193.0 wide with a side wall above and below it.
2. Dust flaps. Each side wall keeps a 25 mm flap at each end, between 183.0 and 208.0 from the end. Trim 1 mm off the flap's outer edge. Cut out the 4 mm notch between the flap and the long strip, from 144.4 to 148.4 across.
3. Tabs. At each end, cut the long strip back by 12.0, leaving two tabs 30 wide. Each tab runs from 184.9 to 214.9 from a long edge.
4. Hook window. At each end, cut out the slot between 28.8 and 33.1 from the end. It runs from 164.9 from one long edge to 164.9 from the other (160.0 long).
5. Hem sides. From each end of that slot, cut straight on to crease C: two cuts per end, from 33.1 to 44.8 from the end.
6. Wall slots. Two per end, between 77.4 and 81.9 from the end. Each runs from 184.4 to 215.4 from a long edge.

## Body: crease

Press a blunt edge along a ruler. Do not cut through.

Fold toward you, so score this face:

- Floor to side walls: the two long strip edges, only between the side wall ends (208.0 from each end).
- Crease A: 204.0 from each end, across the long strip.
- Dust flaps: 208.0 from each end, across each flap.
- Hem: crease C, 44.8 from each end, only across the window.

Fold away from you, so turn the board over and score the back:

- Crease B: 57.6 from each end, across the long strip.
- Crease C beside the window: the two short lengths between the strip edge and the window.
- Crease D: 22.8 from each end, across the long strip.

## Lid

Cut a rectangle 224.6 x 282.0. Score two lines along the 224.6 direction, 40 in from each long edge, and fold both flaps toward you. The face you scored is the underside.

## Liner (5 mm foil bubble)

Cut with scissors. Two of each.

| Piece | Size | Goes |
|---|---|---|
| Floor and lid | 211.4 x 188.0 | One on the floor, one glued under the lid |
| Side | 211.4 x 136.4 | Along each long wall, standing on the floor piece |
| End | 178.0 x 136.4 | Between the side pieces at each end |

## Fold and fix

1. Fold the two side walls up.
2. Fold the four dust flaps in.
3. Fold the end walls up outside the dust flaps and tape the flaps to them.
4. At each end fold the ledge out and the drop panel down.
5. Fold the return panel in, push the two tabs through the wall slots, fold them down inside and tape them.
6. Fold each hem up and back onto its ledge and glue it flat.
7. Fold the lid flaps down and set the lid between the two ledges.
